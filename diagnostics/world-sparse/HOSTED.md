# Optional hosted adapter for the manual sparse World probe

This adapter extends the seven-file manual tool. It appends one independent job to the existing four-tabs workflow, not a new workflow, required QA job, package gate or manual dispatch. It does not change App/Core, launch flags, selectors, the manual runner or its exact instrumented C79 source. There is no deployment, signed install, physical phone or production data.

Only a push to qianshou330-cyber/pubo-ios:ui-four-tabs-148-20261112 with [world-sparse-probe] in the **head commit message** opts in. The Actions condition uses its usual case-insensitive contains; preflight requires the exact lowercase token before any native work. The existing workflow's push concurrency/cancellation policy remains unchanged; do not push to trigger this while another desired run is active.

- Checkout is at the event SHA without persisted credentials, with full history. Preflight requires a non-shallow checkout at that SHA, the exact C79 commit as an ancestor, and hashes matching all seven manual files. The driver runs from the marked head; the native build uses a new git archive of C79 plus a checked six-source instrumentation diff. It is not the current HEAD's unmodified app binary. Read README.md for data flow and limitations.
- Disposable GitHub-hosted Intel macOS 15 only; existing Xcode 26.0.1 (17A400) via DEVELOPER_DIR, preinstalled Python 3.11+, and XcodeGen. Only install XcodeGen if absent, using the existing page2 job's Homebrew route. Brand/XcodeGen generation occurs once in the archive, followed by one unsigned generic x86_64 Debug build, one new iPhone 17 Pro Max iOS 26.1 simulator and one method via its fresh .xctestrun. No other runners, platform fallbacks, matrix, simulator image installs or workload retries. Normal dependency resolution is the pinned project's own (including SDWebImage).
- All simulator shutdown/delete operations target only the UUID returned by that invocation's simctl create; no erase or delete against existing or all devices. The inherited boot helper permits one restart before tests and can restart the simulator **service** on the disposable CI host on failure. This service restart is not a per-device operation; the hosted guard rejects self-hosted jobs before it can run. This adapter does not add a simulator-control command.
- The artifact name includes the trigger SHA, run ID and attempt. Context/initial UNAVAILABLE exist before checkout. Always upload available evidence from the outside-checkout pubo-sparse-host/ directory: native build/test logs, partial or finished xcresult, attachments, receipt, observation, source diff and identity if produced. Whole-VM loss or forced cancellation can prevent upload. Missing raw receipts, skipped/zero-test runs, build/boot failures and ordinary XCTest passes alone cannot establish an exercised sparse branch.
- status.txt and the job summary distinguish EXERCISED_SYNTHETIC (driver 0, validated changed binary-path capture); UNEXERCISED (driver 3, valid gestures/viewport movement but no qualifying capture; final step exits **3**); UNAVAILABLE (setup, native execution, or evidence failed; final step exits **1**). Final classification rechecks the raw app/gesture receipt and screenshot hashes against the pinned driver's result. Both non-success outcomes make this optional job red: there is no neutral shell exit code. The overall **marked** workflow can therefore be red, though all required checks and package dependencies are unchanged. Inspect native/identity.json, logs and xcresult before attributing a mismatch or infrastructure error to the product. No frame-rate, hitch, real-device, socket-delivery or perceived speed claim follows.
