# H5 通知页核对

2026 年 11 月 11 日从 PUBO 当前公开站点获取前端。浏览器为 Codex 内置浏览器，页面视口为 440×956 CSS 像素。页面的请求和实时事件均来自本地隔离服务。20 个标准通知类型和两种聚合展示使用与 iOS 相同的合成数据。[来源与校验](source.json)

## 分类与未读

| 操作 | H5 实际表现 | 证据 |
|---|---|---|
| 打开「全部」的筛选菜单 | 20 项。分别选中后，列表显示该类型。回应和转贴筛选各保留单人及聚合记录。 | [逐类记录](categories.json) |
| 首次及继续分页 | 首次限 20 条，「查看更多」读取剩余记录。登录和访问令牌两类位于第二页。 | [行与链接](rendered-rows.json) |
| 打开「提到我的」 | 列出提及本人的公开帖子和指定用户可见帖子。点帖子日期打开对应详情，返回原通知页。 | [原始点击](note-tabs.json) |
| 打开「私信」标签 | 仅列指定用户可见帖子，显示信封范围标记。点开同一条帖文并返回。 | [原始点击](note-tabs.json) |
| 首页角标为 12 时进入通知 | 有数据的全部列表加载后，底部铃铛角标清零。 | [角标录像](videos/unread12-to-zero.mp4) |

## 点击目标

新帖、提及、回复、引用、回应、转贴、问卷结束及定时发布成功均打开相应帖文。转贴通知保留转贴节点 ID。头像和昵称打开对应用户。成就进入成就列表，导出进入具体文件，创建令牌进入应用设置。群邀请的群名、角色名、登录提示、定时发送失败、测试通知和样例中的应用纯文字均留在通知页。[22 种形态与返回记录](routes-final.json)

四条较深的条目初次自动点击时，长列表滚动尚未稳定。随后分别使用单一类别和滚动居中的全部列表复测，两次均打开正确对象并返回。原始失败与复测记录均可核对。[全部尝试](routes.json)

标题行高 50，类别行高 40。全部列表第一个条目在 y=103，宽 416、高 66。头像 42×42，文字起点 x=74，条目内侧留白 12。默认字号下姓名和摘要为 11.9 CSS 像素，时间为 10.71 CSS 像素。[实际尺寸](measurements.json)
