# PUBO iOS 通知页

## 浏览与筛选

底部的“通知”打开“全部”。顶部筛选一次选择一种类型，菜单中的“清除”恢复全部。“提到我的”显示提及本人或指定本人可见的帖子。“私信”标签只显示指定用户可见的帖子。一对一与群聊消息仍从底部“私信”进入。

“全部”按服务器返回聚合连续表情回应及转帖。点帖子摘要打开相关帖子，点参与者头像进入对应主页。回复、提及、引用显示帖子卡片。无可操作正文的应用通知与测试通知可原地阅读。

## 角标与刷新

首页等其他页面显示服务端的通知未读数量。超过 99 条显示 99+。旧响应只有未读状态时显示圆点。通知行没有逐条已读字段。进入有效非空的“全部”列表后，服务器按其原有规则清除总未读数。勾形按钮可主动全部标记为已读。通知已读与聊天已读分别处理。

在顶部下拉时显示“下拉刷新”，手指移动约 200pt 后显示“松开以刷新”。松手后显示“刷新中”，直到首屏请求结束。短距离下拉后松手会收起提示。向上滚动可以加载更早通知。列表顶部接收实时新通知，阅读历史时先暂存，回到顶部后插入。新通知入场约 700 毫秒。开启减少动态效果时取消入场位移。重新连接后核对最新列表。返回后保留原筛选。

## 目的地

成就通往成就页。导出通知用文件 ID 鉴权查找文件。创建访问令牌通知通往当前账号的已授权应用，登录通知通往当前账号的登录记录。访问这些账号安全页面沿用原生身份复核。关注请求可就地接受或拒绝。原生保留了群聊邀请、角色和定时失败等通知的相关页面入口。
