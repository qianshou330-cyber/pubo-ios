# H5 与原生 App 功能自查

核对日期：2026-11-01。对象：PUBO 正式 H5 对应源码 `pubo-home-first-visit-work` 与原生 0.1.2/build 7。**结论：当前 App 是核心社交原生首版，没有 H5 的全部功能。界面接近不代表功能等同。**

核对方式：检查网页路由、相关页面/组件和原生界面、请求及数据流；首页、登录、注册须知另有访客 H5 实际浏览器对照。没有逐一操作生产的全部功能，未发送生产短信、帖子或私信。路由存在不代表后台当前已启用，例如贪吃蛇入口仍受关闭设置约束。

“已有”表示原生存在对应实现；不表示已完成实体 iPhone 验收。“部分”说明限制；“网页”表示依赖系统浏览器，不能计作完整原生支持；“缺失”表示没有原生入口/实现。这里不计算容易误导的功能覆盖百分比。

## 首页与账号

| 能力 | 原生状态 | 具体差距与证据 |
|---|---|---|
| PUBO 品牌、浅深色、注册与登录入口 | 已有 | `AuthView`、`PUBOTheme`；按当前 H5 同步标志、卡片、按钮和留白 |
| 首页公告、公告详情与已读 | 缺失 | H5 `MkVisitorDashboard`、公告组件和 `/announcements`；原生欢迎页仅品牌/账号/有效政策链接 |
| 访客公开时间线与桌面滚动预览 | 缺失 | 原生 `AuthView` 不显示访客动态；登录后才有时间线 |
| 音乐榜单、首页榜单卡片、活跃统计 | 缺失 | H5 `/music-charts/kpop` 等；原生首版未接入 |
| 短信注册、邮箱/邀请码条件 | 已有 | `AuthView` 使用实际 meta、`signup/request-phone-code`、`signup`；验证码/限流由服务器处理 |
| 注册规则/政策/注意事项确认 | 部分 | 原生显示实际可用规则和 HTTPS 政策；站点目前缺有效条款/隐私地址，不能称分发条件已齐全 |
| 用户名及密码校验 | 部分 | 原生有格式/密码一致检查和显隐；没有 H5 用户名实时占用查询、密码强度反馈 |
| 用户名→密码登录、TOTP | 已有 | `AuthView` 使用 `signin-flow`，密码不持久化，凭据存 Keychain |
| 通行密钥、网页验证码 | 网页 | 系统授权窗口完成 MiAuth；不是原生 Passkey/验证码界面 |
| 忘记密码、恢复账号 | 缺失 | 无专门原生流程；完整网站功能不能据“网页登录”按钮视为已实现 |
| 单账号会话、退出及本机清理 | 已有 | `AppSession`、`KeychainStore`、`ProtectedStore` |
| 多账号切换、多站点 | 缺失 | 固定 bolubo.com，一次一个账号；H5 账号管理未同步 |

## 动态、帖子、媒体与通知

| 能力 | 原生状态 | 具体差距与证据 |
|---|---|---|
| 关注/本地/全球时间线、分页、刷新 | 已有 | `TimelineView`；服务器仍会执行权限，当前没有与 H5 一样预先隐藏所有禁用选项 |
| 混合时间线、列表/天线/频道时间线 | 缺失 | 原生只提供 home/local/global |
| 帖子详情及回复 | 部分 | `NoteDetailView` 读取最新 30 条回复，没有完整回复分页/会话树 |
| 发文字、回复、转发、引用转发 | 已有 | `ComposeView`、`NoteCard` |
| 发帖入口与编辑界面 | 部分 | 0.1.2 已验收同步普通铅笔、白底黑字、顶部头像/可见范围/矩形发帖按钮及图标工具栏，支持正文/CW/附件/简单预览；仍保留原生四页导航，入口在动态页顶部。没有照搬 H5 所有入口位置，也没有未实现的网盘、投票、定时发布等虚假按钮 |
| 可见范围、CW | 部分 | 公开/首页/关注者及 CW 已有；指定用户可见、仅本站传播等高级项未提供 |
| 图片/视频上传、草稿、结果不确定保护 | 已有 | 原生相册选择，最多 16 项；单项 50 MB 客户端上限，不确定发送不盲重试 |
| 拍照/拍视频、媒体编辑与标记 | 缺失/部分 | 没有内置相机拍摄入口；没有上传时敏感标记、图片说明、裁剪/水印等完整功能。权限说明存在不等于拍摄已实现 |
| 图片/音视频查看及敏感遮蔽 | 部分 | 图片缩略预览、音视频系统播放器、敏感内容手动显示；无完整图库缩放/保存体验 |
| 自定义表情与帖子反应 | 部分 | 异步表情/搜索/添加取消反应已有；反应汇总仍显示文本短码，缺 H5 表情分组/收藏/完整反应详情 |
| MFM、提及/话题链接、链接预览 | 部分 | 纯文本及自定义表情；不具备完整 MFM 渲染和点击路由。复杂内容有原帖网页入口 |
| 投票展示/投票/创建 | 网页/缺失 | 已有投票提示跳转原帖网页；原生不能投票或创建投票 |
| 收藏、剪藏、帖子置顶、删除/删除重写 | 缺失 | 原生 NoteCard 未提供这些操作 |
| 搜索帖子、话题搜索、探索/热门 | 缺失 | 仅“新私信”里有本站用户搜索，不是全站搜索 |
| 通知列表、分页、全部已读、前台更新 | 已有 | `NotificationsView`、`StreamClient` |
| 通知分类/过滤、关注申请审批 | 缺失 | 可展示部分通知类型，但不能原生批准/拒绝关注申请 |
| 锁屏推送/后台持续接收 | 缺失 | 没有 APNs；退后台关闭 WSS，回前台刷新 |
| 网盘目录、存量附件选择、管理/清理 | 缺失 | 仅通过发帖上传文件，无独立网盘界面 |

## 私信

| 能力 | 原生状态 | 具体差距与证据 |
|---|---|---|
| 单聊、会话列表、本站用户搜索 | 已有 | `ChatListView`、`UserSearchView`、`ChatView` |
| 首条文字限制、回复解锁、管理员等服务器规则 | 已有 | 复用实际接口，显示业务错误；收到回复不自动投递积压消息 |
| 图片/视频/文件、受保护附件访问 | 已有 | 专用 `chat/attachments/create` 与认证 original 请求，`attachmentIds`；不冒用公开网盘文件 |
| 语音录制及播放 | 已有，真机待测 | 原生最长 60 秒，系统播放器；麦克风授权、扬声器/耳机实际体验待签名安装验证 |
| 引用回复、复制、已读 | 部分 | 可以引用/复制/标已读；不能点引用跳到完整消息上下文 |
| 置顶、免打扰 | 已有 | 会话滑动操作、`chat/conversation-settings/update` |
| 稳定发送 ID、草稿、失联核对、手动重试 | 已有 | `PendingChat`/`Outbox`/`ChatView`；24 小时待发，不自动盲重发 |
| 编辑已发消息、撤回 | 缺失 | H5 `XMessage.vue` 调用 update/delete/state；App 没有操作入口，只能显示已返回的撤回状态 |
| 消息表情回应/取消回应 | 缺失 | H5 react/unreact；App 的“插入表情”是文字，不是消息反应 |
| 旧消息变更完整补取 | 部分 | App 重连重新取最新列表；没有 H5 按已加载消息 ID 批量查询 state，较旧消息编辑/撤回可能要重新进入或加载后才更新 |
| 聊天搜索/上下文定位、联系人管理 | 缺失 | 原生只有新私信用户查找和分页读取 |
| 群聊/房间/邀请/成员管理 | 缺失 | H5 房间路由与相关页面未原生接入 |

## 验证与后续优先级

已有测试只覆盖声明的场景：核心单测、两种 iPhone 模拟器界面测试、独立隔离后端 HTTP 契约。不能将它们当作全部 H5 功能或实体 iPhone 的端到端验收。精确 CI 提交和设备 IPA 校验见同目录 evidence 中最终记录。

建议下一批优先：首页公告/访客动态，忘记密码入口，私信编辑/撤回/回应及完整状态补取，用户头像/横幅与搜索收藏。榜单/游戏/后台属于独立模块，另行排期。**本轮按要求完成自查和真机 SDK 未签名 IPA，不把这些缺失功能默认为已补齐。**
