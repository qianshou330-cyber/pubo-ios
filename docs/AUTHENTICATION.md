# 0.9.1 登录与注册

以已交付的 0.9.0/build105 为基础，恢复 build73 静态欢迎背景。浅色黑 Logo、深色白 Logo。新版包不包含 login-background.mp4 和 login-background-poster.jpg；旧资源在原版本源码备份中保留。

## 原生页面

- 登录居中弹窗上限 400×450pt，注册 500×600pt；窄屏留 16pt 边距，键盘出现时按可用区域缩小，正文可滚动。关闭按钮 44pt，没有底部拖动条。
- 标题栏、账号头像、输入框、规则分组、注册同意确认按 H5 校准。步骤切换为 300ms 淡入与横移，减少动态时仅淡入。
- users/show 读取账号展示信息，signin-flow 决定密码、动态验证码、通行密钥或完成步骤。32 位备用码有独立切换，关闭或更换账号清理密码与验证码。
- 注册用户名与按配置启用的邮箱预检延迟 300ms，取消旧请求，并检查当前输入和页面生命周期。预检失败可重试，结果必须与提交输入一致。
- 密码强度使用 H5 同一计算规则，仅提示、不增加注册强度门槛。手机号去除空格、短横线和 +86 前缀。短信成功响应才开始 60 秒倒计时，超时不重发。
- 忘记密码支持邮箱申请和手机号重置。邮箱链接仍在网站处理；手机重置成功回到登录。提交重置短信只表示申请已受理，不推断手机号已绑定账号。
- 所有凭据只驻留内存。关闭页面取消操作，迟到响应不能推进已关闭流程；AppSession 安装账号前再次检查取消状态。

## 保留差异

- 通行密钥和网页安全验证继续使用系统安全授权窗口；不仿造网站验证器。启用网页验证码的注册转到网站。
- 网站浅色欢迎页 Logo 仍为白色，App 按用户要求使用黑色。原生安全区域、键盘、系统字体、弹窗与 H5 浏览器存在系统差异，不宣称逐像素相同。
- 线上条款/隐私配置存在无效网页地址。App 不照搬无效链接，隐私保留本站 /privacy.html；未修改线上配置。
- 原生手机重置增加重复输入新密码；邮件中的完成链接由网站处理。

## 验收方式

主机型 iPhone 17 Pro Max（440×956pt），补测 iPhone SE 3；浅深主题、可访问字号、键盘、取消、错误、限流、前后台恢复均由专门 UI 测试覆盖。H5 在内置浏览器运行当时公开页面的只读本地副本，认证响应由隔离合成数据提供，生产写请求为零。

内置浏览器逻辑视口为 440×956，但截图/录屏工具实际只返回上部 440×802；对比材料必须注明这个裁切，不补造缺失区域。原生记录实际模拟器屏幕，录屏保留源时间戳。

scripts/isolated/auth-contract.mjs 只在 GitHub 测试环境运行，对固定本地后端验证注册、验证码、备用码、短信限流、邮箱申请与手机重置。短信提供商和邮件发送为本地测试通道；不调用生产短信、邮件服务，不存储凭据到交付日志。

运行 swift test、Python 封装测试、auth-static.yml 双尺寸界面与 Release 构建，以及 native-integration.yml 真实隔离接口验收。候选编译通过不等于最终验收通过，准确数量、失败记录、IPA 哈希见同版本交付目录。

实体 iPhone、最低 iOS 17 实际运行、真实短信/邮件、签名安装与覆盖升级需单独验收。交付未签名 iPhoneOS arm64 包，需另行签名才能安装。
