# 0.8.0 / build77 社交对齐候选

以 build74 为基线，只调整普通用户页面。旧包及修改前源码保留于本地交付目录。

- 帖子区分纯转发、引用和回复；原帖摘要一层展示，保留 CW/权限不可见状态，点击进入对应原帖。
- 通知按类型进入群聊、成就、导出文件、关注申请和账号安全等页面；补指定可见帖子列表。导出文件按认证 ID 读取，不接受通知中的任意下载地址。
- 正文、内容提示及聊天长度在发送前校验，超限保留输入并明确提示。使用原生文本选区插入表情、话题与提及。
- 群聊自己消息靠右，补本地附件/相册、表情输入、反应切换和成员/搜索/关于入口；不新增服务端没有的群聊语音、引用或编辑能力。
- 私信增加录音按钮、受鉴权保护的行内图片/语音和会话设置。文件大小限制、稳定发送标识、撤回/引用同步及未知结果核对保留。
- 阅读历史时新消息提供回到最新提示；会话显示时间和附件类型摘要。

本候选新增核心边界测试与普通页面 UI 测试，沿用双尺寸模拟器、Release 与真实隔离后端工作流。编译、截图、录屏及运行结果尚待执行，不将实现存在视为验收通过。

截图主设备 iPhone17 Pro Max（440×956pt），小屏为补充回归。真实 iPhone、最低 iOS17、签名安装和硬件录音待验。APNs 仍关闭；不改网站、Bot、采集调度、数据库/Redis 服务或其他应用。

候选75专项发现发帖编辑器的 FocusState 在切换 UITextView 后失去绑定目标，连续输入首字后失焦；76改用由 UITextView 维护的普通状态。保留连续61字符与超限/回删断言。网盘选择器实际按钮为取消，修正测试定位并额外断言页面标题，不改产品按钮。

77沿用76产品代码，仅修正隔离搜索测试对可点击正文的定位：按后端实际帖子ID查找按钮，仍断言完整正文及收藏服务端回执。75失败截图与无障碍层级确认帖子已正常出现，原测试错误地只寻找StaticText。最终运行结论记录于交付目录的验收文件。
