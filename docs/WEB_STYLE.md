# PUBO 原生界面与网页风格

0.1.1 / build 2 保持 SwiftUI 原生实现和现有四页导航。网页基准为
`pubo-home:first-visit-20261031-v4` 的默认主题、访客卡片和私信组件。
2026-11-01 只读 `/api/meta` 确认站点没有额外的默认主题覆盖。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F9F9F9` | `#0C1210` |
| 卡片 | `#FFFFFF` | `#192320` |
| 正文 | `#676767` | `#DEE7E4` |
| 强调色 | `#86B300` | `#B4E900` |
| 注册按钮 | `#2DC100`、白字 | 同左 |
| 发帖按钮 | 白底黑字 | 同左 |
| 自己的聊天气泡 | 强调色 15% + 卡片 85% | 同左 |

共享样式在 `App/Components/PUBOTheme.swift`。卡片圆角 12pt，按钮胶囊形，
主要点击区域至少 44pt；文字随系统字号缩放。欢迎页复用原品牌图片、居中卡片、
注册与登录入口，表单以原生窗口打开。动态选择器使用网页的下划线形式。
聊天输入框与工具栏分成两行，接收方头像在左，发送方气泡在右；已读及发送状态
放在气泡外。待发错误、人工重试与移除仍在发送方一侧，不创建系统消息。

系统键盘、相册、文件选择、权限提示、原生底部导航和页面返回手势继续遵循 iOS。
此轮统一视觉，不新增公告、榜单、小游戏或网页后台功能，也不载入网页作为核心界面。
账号权限、网络层、Keychain、数据库契约及发送对账流程沿用原实现。

测试全部使用合成数据，界面截图不是生产用户帖子或真实私信。
浅深主题、欢迎与注册窗口、动态/通知/会话/聊天、小屏与大屏、大字体键盘均需
在对应提交的云端模拟器实际验收。结果见 `STATUS.md` 及结构化验收记录。
真机、签名与原生 UI 连接隔离后端的联合端到端验收仍独立记录。
