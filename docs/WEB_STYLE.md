# PUBO 原生界面与网页风格

0.1.1 / build 2 保持 SwiftUI 原生实现和现有四页导航。网页基准为
`pubo-home:first-visit-20261031-v4` 的默认主题、访客卡片和私信组件。
2026-11-01 只读 `/api/meta` 确认站点没有额外的默认主题覆盖。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F9F9F9` | `#0C1210` |
| 卡片 | `#FFFFFF` | `#192320` |
| 正文 | `#676767` | `#DEE7E4` |
| 强调色 | `#86B300` | `#B4E900` |
| 注册按钮 | `#2DC100`、白字 | 同左 |
| 发帖按钮 | 白底黑字 | 同左 |
| 自己的聊天气泡 | 强调色 15% + 卡片 85% | 同左 |

共享样式在 `App/Components/PUBOTheme.swift`。卡片圆角 12pt，按钮胶囊形，
主要点击区域至少 44pt；文字随系统字号缩放。欢迎页复用原品牌图片、居中卡片、
注册与登录入口，表单以原生窗口打开。动态选择器使用网页的下划线形式。
聊天输入框与工具栏分成两行，接收方头像在左，发送方气泡在右；已读及发送状态
放在气泡外。待发错误、人工重试与移除仍在发送方一侧，不创建系统消息。

系统键盘、相册、文件选择、权限提示、原生底部导航和页面返回手势继续遵循 iOS。
此轮统一视觉，不新增公告、榜单、小游戏或网页后台功能，也不载入网页作为核心界面。
账号权限、网络层、Keychain、数据库契约及发送对账流程沿用原实现。

测试全部使用合成数据，界面截图不是生产用户帖子或真实私信。
浅深主题、欢迎与注册窗口、动态/通知/会话/聊天、小屏与大屏、大字体键盘均需
在对应提交的云端模拟器实际验收。结果见 `STATUS.md` 及结构化验收记录。
真机、签名与原生 UI 连接隔离后端的联合端到端验收仍独立记录。

深浅主题使用相同的字体样式和系统字号。辅助功能大字体仅在用户设置时跟随；自动验收的 --dark 与 --large-text 为独立测试标记。对外截图将正常字号的浅深主题并列，大字体另行展示，避免混排造成深色字号不同的误解。

## H5 首页／账号页二次核对

2026-11-01 对照当前 H5 手机 390px 实际页面及对应正式源码：
- 欢迎卡片：两侧 16pt、内容横向 32pt，原标志调整为 220pt，标题 20pt、介绍 14pt，随系统字号缩放；保留原生安全区和至少 44pt 点击区域。
- 注册：加入注册前须知；显示服务器规则和有效的 HTTPS 条款链接，使用实际 tosUrl 字段。本站当前条款地址为无效配置，不伪造政策，仍是正式分发前待补项。基本注意事项由用户自行阅读确认。
- 表单固定标签、@bolubo.com 后缀、手机号/验证码在密码前、验证码同行按钮、大字体自动换行、密码显隐及两次密码校验；保留服务端最终校验和短信冷却。
- 登录：用户名→密码的原生两步呈现、可更换账号、两步验证输入沿用现有接口；通行密钥或网页验证仍走原有本站安全授权。没有额外查询真实账号或发送短信。
- H5 的公告、榜单和访客时间线以及 Android 下载入口仍与首版功能范围不同；这次同步三个页面的风格与账号交互，不把网站嵌入 App，也不增加此前排除的榜单/游戏模块。
- 生产浏览器只读检查注册须知，未代表用户接受真实条款或创建账号。表单细节依据当前正式源码核对。
