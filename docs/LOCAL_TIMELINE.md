## 数据与生命周期

- `TimelinePreferences` 保存账号或游客独立偏好，迁移既有 `selected-timeline`；服务端请求与订阅使用同一份参数。敏感帖子折叠是客户端语义。
- `TimelineState` 管理分页、待显示队列、引用事件和删除标记。只有明确的删除事件或 `NO_SUCH_NOTE` 才标记删除；断网不等于删除。
- `StreamClient` 保留主通知/私信/群聊连接能力，时间线使用独立标识，旧连接和旧筛选事件被拒绝；帖子订阅按所属页面合并。
- 切换账号/离开页面取消旧任务；公开时间线缓存按账号独立保存，退出账号清理其缓存。附件展开状态不会长期保存。
- 公共图片下载无登录令牌，50 MiB 上限；解码限制尺寸与帧数，缩略展示/放大展示下采样，保存保留原始字节。私信继续现有鉴权。
- 动态文字附件使用明确的 TextKit 初始化和原生动画视图；文字/图片内容未变化时不重建播放视图，避免界面刷新重置有限循环。

## 复现验证

使用 Xcode 26.0.1，主设备 iPhone 17 Pro Max 440×956pt，小屏 iPhone SE 3。运行前生成品牌资源与项目：

```sh
swift test
python3 -m unittest discover -s scripts -p 'test_*.py' -v
swift scripts/brand-assets.swift
xcodegen generate
PUBO_SIM_SIZE=large python3 scripts/local-timeline-tests.py
PUBO_SIM_SIZE=small python3 scripts/local-timeline-tests.py
```

`TimelineParity.json` 及动画素材为合成测试数据。H5 对比在内置浏览器临时替换响应，不修改服务器文件；完成后恢复主题/视口并清理拦截。截图必须注明原始尺寸、数据来源和任何裁切，不能通过使用不同帖子推断功能缺失。测试资源采样记录模拟器进程内存/CPU，不冒充实体 iPhone 的帧率结论。

真实写入验证仅在 GitHub 临时环境的固定后端、空数据库及合成账号执行。生产端只读抽查。复杂动态 MFM、外站嵌入和网页插件仍使用网页版，本次不增加完整 MFM 引擎。

实体 iPhone、最低 iOS 17 运行、签名安装/覆盖升级、真实系统相册/录音权限及 APNs 仍需单独验收；未签名 iPhoneOS 包必须另行签名后才能安装。
